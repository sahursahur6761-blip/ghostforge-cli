# Security Policy

## Supported Versions

Currently, the main branch of GhostForge CLI is supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within GhostForge CLI, please open an issue in this repository.
Since GhostForge CLI is an offline tool with zero external dependencies and does not transmit data over a network, the primary security concerns involve local file system access (e.g. directory traversal bugs). We take all reports seriously and will work to patch any local privilege escalation or arbitrary file read/write issues.
