# Contributing to GhostForge CLI

We love pull requests! If you wish to contribute, please follow these guidelines:

1. **Zero Dependencies**: Do not add external dependencies (like `requests`, `rich`, etc.) unless it's strictly for a separate, clearly marked plugin/branch.
2. **Keep it Fun**: Maintain the RPG/hacker aesthetic.
3. **Keep it Safe**: Respect the user's filesystem. Do not read outside the current directory, and do not destructively edit project files.

To contribute:
1. Fork the repository.
2. Create your feature branch.
3. Submit a pull request.
